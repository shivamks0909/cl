⚠️ The Problem

Before the Fix

What Was Happening

User clicks survey link ↓ Enters survey ↓ Completes survey ↓ ❌ System doesn't know their source → Direct user? → Supplier user? ↓ ❌ ALL completions → SAME landing page (Wrong for suppliers!)

❌ Broken Behavior

  • Direct users need internal PanelFlow page
  • Supplier users need vendor's external site
  • Source NOT saved to database
  • Analytics can't segment traffic

✅ Desired Behavior

  • Track source at entry point
  • Store in responses.source
  • Direct → /complete (internal)
  • Supplier → vendor redirect URL

🔍 Root Cause

Four critical bugs prevented the source field from being captured and stored.

Key Insight

The source field in the database is the single source of truth that determines where the user ends up after completing the survey.

🗄️ Database Schema

The responses table already had a source field

CREATE TABLE responses ( id UUID PRIMARY KEY, project_id UUID, project_code TEXT, uid TEXT, -- Respondent ID clickid UUID, -- Session token source TEXT, -- ⭐ 'direct' or 'supplier' ⭐ supplier_uid TEXT, -- Supplier token if applicable supplier_id UUID, -- FK to suppliers table status TEXT, -- 'in_progress', 'complete', etc. created_at TIMESTAMP, ... );

✅ Field Existed, But Was Never Populated

The source column was in the schema, but the application code never set it. This was the core issue!

Sample Query for Analytics

SELECT source, COUNT(*) as total_entries, COUNT(CASE WHEN status = 'complete' THEN 1 END) as completes, ROUND(COUNT(CASE WHEN status = 'complete' THEN 1 END) * 100.0 / COUNT(*), 2) as conversion_rate FROM responses GROUP BY source;

🎯 RedirectResolver Logic

Priority-based resolution algorithm

static resolve(status, project, supplier, link, uid, pid, source) { const isSupplierFlow = source === 'supplier' || !!supplier; // Priority 1: Link-level redirect (supplier only) if (isSupplierFlow && link?.custom_complete_redirect_url) { return { url: link.custom_complete_redirect_url, isExternal: true }; } // Priority 2: Supplier-level redirect (supplier only) if (isSupplierFlow && supplier?.complete_redirect_url) { return { url: supplier.complete_redirect_url, isExternal: true }; } // Priority 3: Custom landing page overrides... // Priority 5: Project-level landing page (any flow) if (!targetUrl && project?.project_landing_page_url) { return { url: project.project_landing_page_url, isExternal: true }; } // Priority 6: Fallback to platform defaults return { url: `/${status}`, isExternal: false }; }

Key Points

  • isSupplierFlow checks both source === 'supplier' and supplier object exists
  • Direct flows skip supplier-specific priorities
  • Injects parameters ({uid}, {pid}) into final URL
